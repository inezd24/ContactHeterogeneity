# Data

This folder is a placeholder. The scripts in `src/` do not read from this folder directly — as provided, they point at absolute paths on the author's HPC account (see the main [README](../README.md#adapting-paths-to-your-own-system)). This file documents what those paths expect, so the input data can be dropped in and the paths updated accordingly.

## Expected input files

- `ServerData.rds` — one per location (referenced as `~/BaseData/Chad/ServerData.rds` for the primary location, and via `FILE_DIR` + country/location arguments for the other three: Romana, Sabaneta, Habi, Hepang). This is the empirical dog-contact edgelist/dataset that networks are constructed from and compared against.
- Intermediate pipeline outputs (vetted graph ensembles, `MASTER_ENSEMBLE_FOR_DM.rds`, per-seed summary CSVs, etc.) are generated by the numbered scripts themselves under `Net_Sens/`, `Outfiles/`, and `Plots/` subfolders of `LOCAL_ROOT_DIR` — these are pipeline outputs, not inputs, and are not tracked in this repository.
